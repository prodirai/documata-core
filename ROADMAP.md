# План развития

План описывает последовательность разработки Documata Core. Сроки и состав этапов уточняются по результатам реализации и проверок.

| Этап | Результат | Статус |
| --- | --- | --- |
| **01 · Проектирование** | Архитектура, модель данных, контракты API | В работе |
| **02 · Основной цикл** | Документы, редакции, права доступа и подписание | Запланирован |
| **03 · Проверяемость** | Экспорт доказательств, журнал событий и независимая проверка | Запланирован |
| **04 · Первый релиз** | Самостоятельная установка, интеграционные проверки и документация | Запланирован |

## Ближайшие задачи

- Определить модель документов, редакций, участников и подписей.
- Описать контракты API и правила совместимости.
- Реализовать серверные проверки доступа и изоляции организаций.
- Проверить неизменяемость файлов, повторы запросов и конкурентное подписание.

## Критерии первого релиза

- Основной цикл проходит интеграционные и негативные тесты.
- Комплект доказательств экспортируется и проверяется независимо.
- Самостоятельная установка воспроизводится по документации.
- Проверены безопасность, восстановление данных и ограничения эксплуатации.
- Опубликованы версия, изменения и требования к обновлению.

Предложения по развитию можно обсудить в [Issues](https://github.com/prodirai/documata-core/issues).
