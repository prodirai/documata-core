Documata Core создаётся для работы с договорами, приложениями и актами: от фиксации редакции до подписания и получения проверяемого комплекта доказательств.

Цель проекта — сделать этот путь прозрачным для пользователей и разработчиков. Каждая подпись должна быть связана с конкретной редакцией документа, а история действий — доступна для независимой проверки.

## Что мы строим

| Возможность | Назначение |
| --- | --- |
| **Редакции документов** | Сохранять исходный файл и историю изменений |
| **Участники и права** | Управлять доступом к документам и действиям |
| **Подписание** | Фиксировать волеизъявление в отношении конкретной редакции |
| **Доказательства** | Экспортировать документ, события и сведения для проверки |
| **API и самостоятельная установка** | Встраивать ядро в свои продукты и инфраструктуру |

**Стадия проекта:** ранняя разработка. Локальная библиотека сохраняет документы и подписи в SQLite. Доступны [транзакционная модель](docs/local-architecture.md), [контракт подписания](docs/api-v1.yaml) и автономная проверка контрольных сумм.

Для проверки требуется Python 3.12+, macOS или Linux с libseccomp2.

```sh
python3 -m venv .local/venv
.local/venv/bin/pip install --require-hashes -r requirements.lock
.local/venv/bin/python -m unittest discover -s tests -v
.local/venv/bin/python -m documata.export evidence.zip
```

Обработчик PDF использует pypdf (BSD-3-Clause). Проверка ZIP показывает согласованность содержимого с манифестом. Юридическая оценка и независимое заверение реестра требуют отдельных оснований.

## Принципы

- **Неизменяемость.** Новая редакция сохраняет историю предыдущих документов и подписей.
- **Проверяемость.** Значимые действия связаны с участником, временем и содержимым файла.
- **Безопасность.** Проверка доступа и изоляция данных заложены в основу архитектуры.
- **Открытость.** Ядро развивается под Apache 2.0 и рассчитано на самостоятельное использование.
