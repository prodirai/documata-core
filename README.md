# Documata Core

Открытое ядро Documata для жизненного цикла документов, подписания и проверяемых доказательств.
Лицензия: [Apache License 2.0](LICENSE).

**Статус: подготовлен репозиторий и процесс разработки. Серверное ядро ещё не реализовано.**
Этот репозиторий не содержит работающего сервиса электронной подписи и не предназначен для реальных документов.
Не заявляются сертификация, юридическая готовность или соответствие реализации законодательству РФ.

## Граница ядра

Планируемый состав:
- неизменяемые редакции документов и связи договоров с приложениями;
- проверка доступа, последовательности и полномочий участников;
- фиксация волеизъявления и доказательств с привязкой к конкретным байтам файла;
- журнал событий, экспорт и независимая проверка комплекта доказательств;
- версионированный API, тесты инвариантов и пример самостоятельной установки.

Коммерческий интерфейс, биллинг, обслуживание облака и платные рабочие процессы разрабатываются отдельно.
Базовая безопасность и возможность получить доказательства не зависят от облачной подписки.

## Разработка

1. Прочитайте [архитектурные границы](docs/architecture.md), [правила участия](CONTRIBUTING.md) и [правила безопасности](SECURITY.md).
2. Создайте рабочую ветку от `main` и pull request.
3. Выполните `python3 scripts/check_repository.py`.
4. CI проверяет структуру репозитория, секреты в истории и workflows. Это пока не тестирование серверного продукта.

Первые этапы — модель данных, контракт API, серверные проверки доступа и тесты атомарной фиксации подписи.
Работа с настоящими данными начинается только после отдельной технической и правовой приёмки.

Исходники Documenso/Cinemata и история частного прототипа в этот репозиторий не переносились.
Права на каждый будущий вклад и совместимость его зависимостей проверяются до включения.
