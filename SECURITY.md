# Безопасность

Проект находится в разработке. Production-релизов и гарантированных сроков устранения пока нет.
Используйте только синтетические данные до выпуска проверенного серверного продукта.

Сообщайте об уязвимостях через [Private vulnerability reporting](https://github.com/prodirai/documata-core/security/advisories/new).
Не создавайте публичный issue с персональными данными, рабочими ключами, документами или пригодной для эксплуатации инструкцией.
Опишите версию, ожидаемый результат и минимальное воспроизведение на вымышленных данных.

Исправления выпускаются через проверяемые pull request; срочные исправления также проходят CI.
Репозитории и журналы CI не являются хранилищем документов пользователей.
Секреты хранятся отдельно от исходников, контейнеров и резервных копий ключей.
