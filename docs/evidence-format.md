# Протокол локального реестра v1

ZIP содержит manifest.json, protocol.json, original.pdf и готовую производную copy.pdf при наличии. Хеши SHA-256 вычисляются по точным байтам. Канонический JSON снимка использует UTF-8, лексикографическую сортировку ключей по кодовым точкам Unicode, разделители без пробелов, целые числа в десятичной записи, null для явно отсутствующего значения. Строки сохраняются без нормализации Unicode. В подписываемом снимке запрещены повторяющиеся ключи и дробные числа.

Дополнительное поле registry_seal подписывает каноническое представление всей записи стороны до добавления самого поля. Реестр использует ECDSA P-256 и SHA-256, DER-подпись представлена base64. Идентификатор ключа — SHA-256 от точных байтов открытого ключа SPKI в PEM. Часы локальной машины и результаты simulated входят в снимок. Ключ реестра удостоверяет запись учебной системы. Пользовательский challenge и независимое доверенное время имеют другую область действия.

Передайте доверенный registry.public проверяющему отдельно от ZIP. Команда `python -m documata.export evidence.zip --trusted-key registry.public` сверяет комплект и заверения сторон. Без отдельного ключа доступны проверки контрольных сумм. Старые записи без заверения читаются и явно не проходят режим проверки доверенного ключа. Закрытый ключ остаётся в каталоге стенда. Защита отдельным устройством и внешний журнал контрольных точек требуют эксплуатационного контура.
