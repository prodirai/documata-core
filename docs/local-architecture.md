# Локальная архитектура

Ядро представляет собой библиотеку Python с транзакционной моделью SQLite и приватным каталогом неизменяемых файлов по SHA-256. Лицензия собственного кода Apache-2.0, Python и SQLite используются из стандартной поставки интерпретатора. Обработчик PDF запускается отдельно с ограничениями ресурсов. API v1 передаёт сервером установленный субъект и выбранную организацию. Доступ сверяется с действующим членством или назначением получателя. Публичный поиск контрольной суммы раскрывает только факт регистрации файла.

| Переход | Действующее лицо | Условия на момент записи |
|---|---|---|
| Черновик → ожидание исполнителя | Назначенный подписант организации | Доступ, действующие полномочия, идентичность, текущая редакция, правила, одноразовый challenge |
| Ожидание → замечания / отказ | Назначенный исполнитель | Идентичность, текущая редакция, надлежащий адресат |
| Замечания → черновик | Подготовитель | Новый проверенный файл, сохранение прежней редакции |
| Ожидание → подписан | Назначенный исполнитель | Подпись первой стороны, отдельное намерение, неизменная редакция |
| Черновик / ожидание → отозван | Организация | Текущее право отзыва, отсутствие завершения |

В одной транзакции выполняются последняя проверка, погашение намерения, запись подписи, снимка доказательств и задача дальнейшей обработки. Повтор подтверждения возвращает прежний результат тому же субъекту. Временные идентификаторы случайны. Замена редакции завершённого договора запрещена. Дочерний документ имеет отдельный цикл. Время в БД — секунды Unix UTC. Локальный источник времени, simulated и версия правил явно указываются в доказательствах.
