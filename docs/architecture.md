# Границы и статус архитектуры

Это целевая архитектура, не описание уже работающего backend.

Ядро должно независимо обеспечивать авторизацию каждой операции, изоляцию организаций,
неизменяемые редакции, атомарную фиксацию подписания и сохранность доказательств.
Коммерческий интерфейс не является доверенной границей: проверка тарифа в браузере не защищает API.
Сервис облака обязан проверять оплаченные права на сервере; ядро отдельно проверяет право доступа к документу.

API ядра версионируется. Ядро не импортирует закрытые пакеты облака. Совместимость проверяется контрактными тестами.
Копирование исходников между репозиториями не используется как механизм обновления.
Реальные документы, PDF, персональные данные и секреты не попадают в публичный CI.

Будущий минимальный комплект самостоятельного развёртывания включает API, PostgreSQL,
закрытое объектное хранилище, фоновые задачи и минимальный клиент.
До появления реализации Docker-образ ядра и фиктивный endpoint готовности не публикуются.

Выбор Apache-2.0 зафиксирован владельцем 19 ноября 2026 года.
Лицензия распространяется на новый собственный код; права на чужие компоненты сохраняются.
