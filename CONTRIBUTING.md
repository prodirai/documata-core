# Участие в разработке

Изменения — через pull request в `main`; обязательны все проверки CI и разрешение обсуждений.
На начальном этапе единственный назначенный сопровождающий — `@izluchator`.
Обязательное второе одобрение пока не включено: автор не может одобрить собственный PR.
При назначении второго сопровождающего включается минимум одно независимое одобрение.

Вклад предоставляется на условиях Apache-2.0. Автор должен иметь право передать вклад на этих условиях.
Не переносите AGPL, GPL или коммерческий код без проверки совместимости и прав; не удаляйте уведомления третьих сторон.
Вопросы лицензирования конкретной зависимости рассматриваются отдельно.

Для изменений подписания обязательны негативные тесты доступа, повторов, гонок и неизменяемости файла.
Для API указывайте совместимость с предыдущей версией и план миграции.
Не прикладывайте реальные документы, номера телефонов, ключи и рабочие журналы.
Релизы ядра и облака версионируются независимо; облако фиксирует точную версию ядра.

Бренд Documata и товарные знаки не лицензируются автоматически вместе с исходным кодом.
