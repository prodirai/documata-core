# Участие в проекте

Спасибо за интерес к Documata Core. Мы принимаем предложения по архитектуре, документации и реализации.

## Предложить изменение

Сначала посмотрите [план развития](ROADMAP.md) и [открытые обсуждения](https://github.com/prodirai/documata-core/issues). Для существенного изменения создайте issue с описанием задачи, ожидаемого результата и возможных ограничений.

Об уязвимостях сообщайте конфиденциально по [правилам безопасности](SECURITY.md).

## Подготовить pull request

1. Создайте ветку от актуальной `main`.
2. Внесите одно логически связанное изменение.
3. Обновите документацию и необходимые тесты.
4. Выполните локальную проверку:

   ```sh
   python3 scripts/check_repository.py
   ```

5. Откройте pull request: объясните задачу, результат и способ проверки.

CI проверяет структуру репозитория, секреты и конфигурацию workflows. Перед слиянием проверки должны пройти, а обсуждения — быть разрешены.

## Требования к изменениям

- Для подписания проверяйте права доступа, повторы, гонки и неизменяемость файлов.
- Для API описывайте совместимость и порядок миграции.
- Для воспроизведения используйте синтетические данные.
- Добавляйте зависимости с понятным назначением и совместимой лицензией; сохраняйте их авторские уведомления.

## Лицензирование

Вклады принимаются на условиях [Apache License 2.0](LICENSE). Отправляя изменение, убедитесь, что имеете право предоставить его на этих условиях.

Использование названия и товарных знаков регулируется отдельно от лицензии на исходный код.
